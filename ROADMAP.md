# Roadmap

This roadmap is a working plan and should be updated as priorities change.

## Priority 1: Foundation

- Confirm product scope and primary user flows.
- Finalize local development environment.
- Create workspace structure.
- Establish documentation baseline.
- Choose Firebase project strategy for development, staging, and production.

## Priority 2: Project Initialization

- Initialize React Native app in `Mobile/`.
- Initialize Firebase backend assets in `Backend/`.
- Add linting, formatting, and TypeScript configuration.
- Add baseline CI checks.

## Priority 3: Product Definition

- Document core user journeys.
- Define initial data model.
- Define authentication requirements.
- Create first design mockups and brand assets.

## Priority 4: MVP Build

- Build initial navigation and screen structure.
- Add Firebase Authentication.
- Add core data reads and writes.
- Add security rules and tests.
- Add basic error and loading states.

## Priority 5: Release Readiness

- Add analytics and crash reporting.
- Review privacy, security, and data retention needs.
- Prepare app store assets.
- Run device testing across supported iOS and Android versions.
