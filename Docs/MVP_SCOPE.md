# MVP Scope

## Required For MVP

- splash/login
- phone authentication
- onboarding/profile setup
- contact permission
- add crush
- phone normalization and hashing
- mutual crush detection
- `pending_reveal` match state
- 6:30 PM IST daily reveal
- anonymous chat
- identity reveal states
- mutual reveal
- unhook
- basic profile
- realtime listeners
- error/loading/empty states

## Deferred

- Premium
- credits
- access skip payments
- voice notes
- disappearing messages
- First Date Packages
- restaurant booking
- Couples Shipping
- Origin Story
- anniversaries
- production WhatsApp sending
- RevenueCat
- full Branch campaign setup

## MVP Guardrails

- Do not add monetization before the core privacy and matching model is stable.
- Do not let payments block Reveal or Unhook.
- Do not treat MongoDB as a production dependency.
- Do not replace Firebase with the preview API.
- Do not expose real identities before mutual reveal.
- Do not send push content that identifies the other person.
