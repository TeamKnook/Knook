# Typography

This document defines placeholder typography decisions for Knook.

## Font Families

| Token | Placeholder | Usage |
| --- | --- | --- |
| font.family.display | System default | Large headings |
| font.family.body | System default | Body text and controls |
| font.family.mono | System monospace | Technical or debug text |

## Type Scale

| Token | Size | Usage |
| --- | --- | --- |
| text.xs | 12 | Captions and helper text |
| text.sm | 14 | Secondary body text |
| text.md | 16 | Default body text |
| text.lg | 18 | Prominent body text |
| text.xl | 24 | Screen titles |
| text.2xl | 32 | Major moments |

## Guidelines

- Keep body text at `16` where possible for readability.
- Avoid relying on text color alone for hierarchy.
- Respect platform accessibility text scaling.
