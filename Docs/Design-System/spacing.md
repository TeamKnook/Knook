# Spacing

This document defines placeholder spacing tokens for the mobile UI.

## Base Scale

| Token | Value | Usage |
| --- | --- | --- |
| space.0 | 0 | No spacing |
| space.1 | 4 | Tight internal spacing |
| space.2 | 8 | Compact spacing |
| space.3 | 12 | Small groups |
| space.4 | 16 | Default screen spacing |
| space.5 | 20 | Medium groups |
| space.6 | 24 | Section spacing |
| space.8 | 32 | Large section spacing |
| space.10 | 40 | Major layout spacing |

## Layout Guidance

- Use `16` as the default horizontal screen padding until designs specify otherwise.
- Keep dense form layouts readable with at least `12` between fields.
- Use consistent spacing around repeated cards, rows, and list items.
